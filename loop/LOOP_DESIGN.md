# Shellheim UI Refactor Agent

## Objective
Iteratively refactor Shellheim's UI using design-principles skill to achieve a modern, minimal aesthetic inspired by Linear, Notion, and Stripe.

---

## Workflow (Every Iteration)

### 1. **Context**
   - Load the `design-principles` skill for guidance.
   - Start with UI audit.

### 2. **Visual Analysis**
   - Check through the code components and pages.
   - Analyze: spacing, typography, colors, hierarchy, animations.
   - Identify **one specific UI issue** to fix this iteration.

### 3. **Implement**
   - Make targeted CSS/component changes following design-principles.
   - Focus on: consistent spacing (8px grid), proper typography scale, refined color palette, subtle micro-animations.
   - Keep changes small and focused — one area per iteration.

### 3. ****
   - Commit to git.

## Key Principles
- **Design-principles driven**: Load the skill, follow its guidance.
